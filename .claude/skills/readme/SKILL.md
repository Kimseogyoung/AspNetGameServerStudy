## 작업 순서

1. 현재 README와 로드맵을 비교해 다음 항목이 최신인지 확인한다:
   - **현재 콘텐츠 범위**: 각 콘텐츠의 서버/클라이언트 L-레벨 반영
   - **기술 스택**: 변경된 기술이 있으면 업데이트
   - **AI 도구**: Claude Code + Serena MCP 사용 여부 반영
2. 기존 포맷(섹션 구조, 마크다운 스타일)을 **그대로 유지**하면서 내용만 갱신한다.
3. 갱신된 README.md를 저장한다.
4. 변경된 섹션 목록을 안내한다.

## 준수 사항
- 섹션 순서, 헤딩 레벨, 코드 블록 형식 등 기존 포맷을 바꾸지 않는다
- 콘텐츠 범위는 로드맵 표(`## 3. 콘텐츠 로드맵 표`)의 `서버 개발 정도` / `클라이언트 개발 정도` 열을 그대로 반영한다
- "개발 예정" 항목은 `L0 미착수` 콘텐츠를 기준으로 작성한다
- 푸터는 "본 README는 Claude Code를 사용해 작성되었습니다." 로 교체한다
- README에 없던 섹션을 새로 추가하지 않는다 (내용 업데이트만)
