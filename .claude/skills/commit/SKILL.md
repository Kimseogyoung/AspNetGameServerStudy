# Git Commit

## 현재 스테이지 상태
!`git diff --cached --stat`

## 스테이지된 변경 내용 (상세)
!`git diff --cached`

## 최근 커밋 스타일 참고
!`git log --oneline -5`

## 작업 순서

1. `git diff --cached` 내용을 분석해 변경의 핵심을 파악한다.
2. 커밋 메시지를 작성한다:
   - **첫 줄(제목)**: 변경의 핵심을 한 줄로 요약 (50자 이내, 한국어)
   - **본문**: 변경사항을 `- 내용` 형식으로 최대 5개까지 나열
   - 최근 커밋 스타일에 맞춘다
3. 스테이지에 아무것도 없으면 커밋하지 않고 안내만 한다.
4. 아래 형식으로 커밋을 실행한다:

```
git commit -m "$(cat <<'EOF'
{주요 제목}

- 변경사항 1
- 변경사항 2
- 변경사항 3
EOF
)"
```

## 준수 사항
- 제목은 명령형/명사형으로 간결하게 (예: "가챠 멱등 키 적용", "RpcMethod 검증 로직 추가")
- 변경사항이 1개뿐이면 본문 없이 제목만으로 커밋해도 된다
- 변경사항이 명확히 6개 이상이어도 가장 중요한 5개만 선택한다
- `--no-verify` 플래그 사용 금지
- 스테이지 내용이 비어있으면 "스테이지에 변경사항이 없습니다. `git add` 먼저 실행하세요." 안내 후 중단
