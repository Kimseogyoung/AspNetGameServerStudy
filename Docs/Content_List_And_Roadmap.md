# 콘텐츠 리스트 및 구현 로드맵

작성일: 2026-03-08  
기준 문서: `Docs/Reference.md`, 현재 서버 구현(RPC 등록/서비스 코드), 기존 기획 문서

## 1. 선정 기준
다음 기준을 만족하는 항목만 로드맵에 포함했다.

1. 기술 검증과 프로젝트 완성도 향상에 유리한 콘텐츠
2. 게임으로 성립하기 위한 최소 핵심 루프
3. 이미 구현되어 있거나 현재 코드베이스에 자연스럽게 확장 가능한 항목

## 2. 현재 콘텐츠 상태 요약

## 2.1 서버/클라이언트 공통 상태
- 인증/입장 루프: 서버는 실동작 가능 수준, 클라이언트는 기본 플로우 동작 수준
- 왕국(기초): 서버는 핵심 기능 동작, 클라이언트는 플레이/편집 UI 동작
- 월드 스테이지: 서버는 보상 포함 핵심 루프 동작, 클라이언트는 진행/완료 동작
- 가챠: 서버는 비용/결과 반영 동작, 클라이언트는 진입/결과 표시 동작
- 쿠키 성장(기초): 서버는 레벨/승급 동작, 클라이언트는 상세/강화 UI 동작

## 2.2 확장 필요 항목
- 서버: 왕국 생산/건설 대기열 기반 처리, 가챠 감사/검증, 쿠키 확장(스킬/토핑/비스킷)
- 클라이언트: E2E 자동화, 공통 에러 처리, 동기화 검증 UI, 운영 로그 가시성

## 2.3 신규 고난도 콘텐츠 후보
- 실시간 레이드 보스(코옵)
- 공방 제작/건설 대기열 시스템
- 시즌 랭킹 + 리플레이 검증
- 길드(가입/기여/버프/레이드)

## 2.4 개발 정도(완성도) 평가 기준
- `L0` 미착수: 기획만 존재, 코드/화면 없음
- `L1` 프로토타입: 단일 경로 동작, 예외/검증/복구 부족
- `L2` 기능 구현: 핵심 기능은 동작, 엣지케이스/운영성 부족
- `L3` 베타 가능: 핵심 루프 + 기본 검증 + 기본 오류 처리
- `L4` 라이브 준비: 운영 로그/회귀 테스트/복구 전략 확보
- `L5` 운영 안정: 성능/관측성/자동화까지 포함한 안정 운영 가능

## 3. 콘텐츠 로드맵 표

| 기획 이름 | 간단 설명 | 예상 개발 기한 | 서버 개발 정도 | 클라이언트 개발 정도 | 우선순위 | 주요 기술 |
|---|---|---|---|---|---|---|
| 인증/입장 루프 | 회원 식별, 세션 발급, 게임 진입, 초기 닉네임 설정 | 완료 | `L3` 베타 가능(인증/세션/입장 동작, 보안·운영 강화 필요) | `L2` 기능 구현(온보딩 플로우 동작, 오류 복구 미흡) | P0 | 세션 관리, 요청 검증, RPC 게이트 |
| 프로필/플레이어 기초 상태 | 레벨/이름/기본 상태 로드 및 변경 | 완료 | `L2` 기능 구현(기초 상태 처리 완료, 메타 확장 부족) | `L1` 프로토타입(표시 중심, 편집/검증 흐름 약함) | P1 | 상태 모델링, DB 매핑, 동기화 |
| 왕국 건설/배치 기초 | 건물/데코 구매, 배치, 건설 완료, 시간 단축 | 완료 | `L3` 베타 가능(핵심 루프 동작, 데이터 구조 리팩터링 필요) | `L2` 기능 구현(기본 UI 동작, 회귀/동기화 검증 부족) | P0 | 상태 전이, 맵 스냅샷, 트랜잭션 |
| 월드 스테이지 진행/보상 | 스테이지 클리어, 별 갱신, 월드 보상 수령 | 완료 | `L3` 베타 가능(핵심 보상 루프 동작, 예외 케이스 강화 필요) | `L2` 기능 구현(진행/완료 UI 동작, 실패 시나리오 미흡) | P0 | 보상 검증, 멱등 보상 처리 |
| 가챠(기초) | 스케줄 기반 뽑기, 비용 차감, 결과 보상 반영 | 완료 | `L3` 베타 가능(핵심 가챠 동작, 감사로그/검증 고도화 필요) | `L2` 기능 구현(팝업/결과 동작, 이력/재시도 UX 부족) | P0 | 확률 처리, 비용 검증, 재화 정산 |
| 쿠키 성장(레벨/승급) | 쿠키 레벨업/승급 처리 | 완료 | `L2` 기능 구현(레벨/승급 완료, 스킬/장비축 미구현) | `L2` 기능 구현(상세/강화 UI 동작, 확장 시스템 미구현) | P1 | 성장 검증, 재화 소모 정합성 |
| 공방 제작/건설 대기열 | 제작/건설을 줄 세워 처리하고 완료 보상을 수령하는 시스템(취소/가속 포함) | 2~3주 | `L0` 미착수(상세 기획 완료) | `L0` 미착수 | P0 | 대기열 처리, 워커, 시간 보정, 멱등 키, 정산 트랜잭션 |
| 실시간 레이드 보스(코옵) | 2~4인 룸 기반 보스전, 틱 시뮬레이션/재접속 복구 | 3~4주 | `L0` 미착수(상세 기획 완료) | `L0` 미착수 | P1 | 룸 인스턴스, 서버 권위 전투, 스냅샷/복구 |
| 시즌 랭킹 + 리플레이 검증 | 시즌 점수 집계, 랭킹, 서버 재계산 검증 | 2~3주 | `L0` 미착수(상세 기획 완료) | `L0` 미착수 | P1 | Redis SortedSet, 검증 파이프라인, 이상치 탐지 |
| 길드(가입/기여/버프/레이드) | 다중 유저 협업 도메인 + 길드 콘텐츠 | 3~4주 | `L0` 미착수(상세 기획 완료) | `L0` 미착수 | P2 | 분산락, 다중 유저 트랜잭션, 이벤트 알림, 감사 로그 |

## 4. 단계별 구현 계획

## Phase A (즉시, 2주) - 현재 구현 콘텐츠 완성도 올리기
- 대상: 인증/입장, 왕국, 월드, 가챠, 쿠키
- 목표:
1. TODO 정리 및 정합성 강화
2. 공통 에러코드/보상 검증 문서화
3. 회귀 테스트 최소 세트 구축

## Phase B (다음, 2~3주) - 공방 제작/건설 대기열
- 이유: 현재 왕국 콘텐츠와 자연스럽게 연결되고 운영 난이도 증명에 유리
- 목표:
1. Job 큐 + 워커 + 멱등 처리
2. 취소/가속/일괄 수령
3. 장애 복구 및 시간 보정

## Phase C (확장, 5~7주) - 고난도 협업/경쟁 콘텐츠
- 대상: 레이드 -> 시즌 랭킹/리플레이 -> 길드
- 목표:
1. 실시간 코옵 전투 구조
2. 시즌 경쟁/검증 시스템
3. 다중 유저 도메인(길드) 완성

## 5. 이번 버전에서 제외한 레퍼런스 요소
`Docs/Reference.md`의 항목 중 아래는 현재 로드맵에서 우선 제외했다.

- 월드 채팅/친구: 기술 난이도 대비 현재 코어 완성 우선
- 아레나(킹덤/아케이드): 레이드/시즌 랭킹 기반 확립 후 재검토
- 업적/기록: 핵심 루프 안정화 후 메타 콘텐츠로 확장
